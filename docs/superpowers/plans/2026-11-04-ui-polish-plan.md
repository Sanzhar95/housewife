# Полировка интерфейса — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Интерфейс на iPhone (390px) стал аккуратнее и живее: на первом экране видно, что готовить сегодня; ничего не налезает; кнопки не занимают пол-экрана; появляются сдержанные анимации. Функции и данные не меняются.

**Architecture:** Только `public/index.html` (CSS + небольшие правки отрисовки). Логика (`logic.js`), база и тексты ошибок не трогаются. Проверка — снимки экранов `node tools/ui-shots.js seed.json папка` (390×844, @2x) на реальных данных семьи и `npm test`.

**Tech Stack:** HTML/CSS/JS без фреймворков, Playwright для снимков.

**Spec:** раздел «Спека» ниже (результат аудита экранов на реальных данных 2026-11-04).

## Спека (результат аудита)

Найдено на 390×844 (отсчёт — CSS-пиксели):
1. **Меню.** Строка «Пора докупить» (≈60px) висит на всех вкладках и обрезает текст («шампи…»); плашка «✨ Новое: порции и «хватает на N раз»» сломана по вёрстке — текст зажат в узкую колонку (5–8 строк), плашка занимает ≈270px; три карточки-счётчика имеют слишком большой межстрочный интервал (≈155px высотой); в итоге заголовок «Сегодня» и блюда на сегодня не видны на первом экране.
2. **Склад.** Три кнопки («Загрузить из Excel», «Список покупок», «Бланк склада») переносятся на два ряда, под ними абзац-подсказка; плавающая кнопка «+ Продукт» перекрывает низ карточек (нет нижнего отступа списка); названия продуктов с маленькой буквы («болгарский перец»); «мин. 0 г» показывается у каждого продукта с минимумом 0 — это шум.
3. **Блюда.** Две кнопки импорта на двух строках; плавающая «+ Блюдо» перекрывает карточки.
4. **Матрица.** Название блюда переносится так, что эмодзи оказывается на отдельной строке над названием; подпись единицы («г») под названием продукта висит отдельной строкой.
5. **Цены/Меню.** Карточки-счётчики: те же большие межстрочные интервалы.
6. **Анимации.** Почти нет (есть только индикатор занятости и правило `prefers-reduced-motion`).

Требования к результату (приёмка по снимкам 390×844):
- Меню: заголовок «Сегодня» целиком (с первым блюдом/приёмом) виден на первом экране без прокрутки, если нет плашки «Новое» (с плашкой — не ниже 740px по y).
- Строка «Пора докупить» — одна строка высотой ≤ 44px, без обрезки слова посередине (при нехватке места «и ещё N»), на всех вкладках.
- Плашка «Новое»: заголовок и текст читаются в 2–3 строки, кнопка и «×» не сжимают текст (кнопка под текстом или в строке заголовка).
- Карточки-счётчики: высота ≤ 110px, межстрочный интервал подписи ≈ 1.25.
- Склад и «Блюда»: кнопки действий в один ряд (прокручиваемый по горизонтали или сокращённые подписи «📥 Из Excel», «🛒 Покупки», «📄 Бланк»); абзац-подсказка про бланк уходит в «Помощь» или сворачивается; нижний отступ списков ≥ высота плавающей кнопки + 16px.
- Названия продуктов и блюд в списках показываются с заглавной буквы (только отображение: в данных не менять); «мин. 0» не показывать, когда минимум 0.
- Матрица: эмодзи в одной строке с названием блюда; единица продукта — мелким текстом в той же ячейке заголовка без лишней высоты.
- Анимации (только `transform`/`opacity`, ≤ 250мс, `prefers-reduced-motion: reduce` отключает все): отклик на нажатие кнопок и карточек (`:active` лёгкое сжатие), плавный выезд шторки снизу и затемнения, появление/исчезновение уведомлений (toast), мягкое появление карточек при смене вкладки, «пружинка» галочки при отметке «приготовлено». Никаких бесконечных или отвлекающих анимаций.

## Global Constraints

- Дизайн-система не меняется: акцент «черника» `#6A55D8`, шрифты Nunito + Caveat, радиусы 14–28px, кнопки-пилюли, светлая тема. Новых шрифтов, библиотек, иконок-наборов нет.
- Терминология как есть: «блюдо», «склад», «меню», «готовить», «вчерашнее».
- Мобильные правила: поля ≥16px, кнопки ≥42px (основные действия ≥48px), диалоги — шторка снизу, нижняя навигация; НЕ класть группы кнопок внутрь `<label>`.
- Логика, действия, данные, `logic.js`, `db.js`, `api.js`, `supabase/` не меняются. Любая правка отрисовки не должна менять то, что записывается в базу.
- `npm test` остаётся зелёным (150 pass / 3 skipped с локальной базой `SUPABASE_DB_URL=$(sh tools/local-pg.sh | tail -1)`; без базы — 18 skipped).
- Safari/iPhone-особенности в среде не воспроизводятся: места, где поведение зависит от iOS (жесты, `100vh`, safe-area, hover), перечислить в отчёте как «проверить на iPhone».
- Снимки: `NODE_PATH=/opt/npm-tools/node_modules node tools/ui-shots.js <seed.json> <папка>`; seed — `/tmp/claude-0/-home-claude/3bc53d5f-663b-5819-883c-c9d494e6ab7e/scratchpad/audit/seed.json` (реальные данные семьи; в git не класть). Каждый результат приёмки проверяется глазами по снимку (Read PNG), а не только по коду.

## Review Focus

1. Размеры ≥42px и перекрытие плавающей кнопкой последней карточки на всех вкладках (прокрутка до конца).
2. Длинные названия и данные: 3 строки названия блюда, длинное имя продукта, 0 продуктов/блюд (пустые состояния), 50+ карточек.
3. Нажатие во время анимации не теряется и не вызывает двойного действия; `prefers-reduced-motion` реально отключает все новые анимации.
4. Заглавная буква только на экране: поиск, сортировка и сохранение (редактирование названия) остаются по исходному значению.
5. Диалоги (шторки) и клавиатура iOS: поля ввода не уезжают под клавиатуру из-за новых отступов/анимаций (проверить на iPhone, пометить).
