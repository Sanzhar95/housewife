# Загрузка блюд из Excel — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новая семья (или любая) загружает свои блюда с составом одним Excel-файлом строгого формата, проверяет их на экране и подтверждает; существующие данные не меняются и не теряются.

**Architecture:** Новое действие `importDishes` в `public/logic.js` (как остальные действия: одна транзакция через `tx_`, запись разницы в базу делает `db.js` без изменений). Разбор файла и бланк — в отдельном чистом модуле `public/import-dishes.js` (работает в браузере и Node). Экран проверки и кнопки — в `public/index.html` на вкладке «Блюда».

**Tech Stack:** JS без фреймворков, SheetJS (уже подключён, только чтение), собственный писатель xlsx `public/xlsx-export.js` (один лист), Node `node:test`.

**Spec:** раздел «Спека» ниже (отдельного документа нет — запрос пользователя: «импортировать эксель, формат даёшь сам, в будущем принимаем только его»). Правки спеки — через ledger.

## Спека

**Проблема.** «Когда у меня пустое приложение, я хочу загрузить свои блюда списком, чтобы не вводить каждое руками.»

**Формат файла (единственный принимаемый).** Один лист, первая строка — заголовок, точно такие столбцы в таком порядке (регистр и пробелы по краям не важны):

| № | Заголовок | Что писать | Пусто значит |
|---|---|---|---|
| 1 | `Блюдо` | название; обязательно в строке, где начинается блюдо | та же строка продолжает предыдущее блюдо |
| 2 | `Тип` | `основное` / `гарнир` / `салат` (также `доп`, `дополнительное`) | основное |
| 3 | `Приёмы пищи` | через запятую: `завтрак, обед, ужин` | все три |
| 4 | `С гарниром` | `да` / `нет` | нет |
| 5 | `Порций в рецепте` | число | 0 (приложение считает по умолчанию 4) |
| 6 | `Хватает на, раз` | целое ≥ 1 | 1 |
| 7 | `Заметка` | текст | пусто |
| 8 | `Продукт` | название продукта | строка без продукта допустима (блюдо без состава) |
| 9 | `Количество` | число (запятая допустима: `0,5`) | обязательно, если указан продукт |
| 10 | `Ед.` | `кг`, `г`, `л`, `мл`, `шт` (синонимы как в `normUnit` из `index.html`) | единица продукта на складе; для нового продукта обязательна |

Столбцы 2–7 читаются из ПЕРВОЙ строки блюда; в следующих строках того же блюда их можно не повторять. Строки с одинаковым названием блюда (без учёта регистра, пробелов по краям, `ё`=`е`) объединяются в одно блюдо, даже если идут не подряд.

**Правила (данные не теряем).**
- Блюдо с таким названием уже есть в приложении — оно пропускается и в отчёте помечено «уже есть»; существующие блюда и их состав никогда не меняются.
- Продукт ищется по названию (регистр, пробелы по краям, `ё`=`е` не важны). Не найден — создаётся новый: единица из файла (обязательна), остаток 0, минимум 0; в отчёте помечено «новый продукт».
- Единица в строке состава должна быть из той же семьи, что у продукта (кг↔г, л↔мл); `шт` только к `шт`. Нарушение — ошибка строки (блюдо целиком не загружается).
- Ошибка в любой строке блюда — блюдо не загружается, остальные загружаются; причина показывается на экране.
- Один и тот же продукт дважды в одном блюде — строки складываются в одну позицию состава (количества суммируются в единице продукта).
- Файл не нашего формата (заголовки не совпали) — загрузка не начинается, сообщение: «Это не наш бланк. Скачайте бланк блюд и заполните его».
- Лимит: не больше 500 блюд и 5000 строк за раз; больше — понятное сообщение, без частичной загрузки.

**UX (телефон, 390px).** На вкладке «Блюда» две кнопки: «📥 Загрузить блюда из Excel» и «📄 Бланк блюд». Бланк содержит 3 примера (с подсказками) и скачивается тем же способом, что «Бланк склада» (`offerXlsx`). После выбора файла — шторка «📥 Блюда из Excel»: сводка («новых: N, уже есть: N, с ошибкой: N, новых продуктов: N»), список блюд с иконками (🆕 / ✔️ уже есть / ⚠️ ошибка + причина); кнопка «Загрузить (N)» (N новых), при N = 0 — «Закрыть». Повторный тап по «Загрузить» не создаёт дублей.

**Метрика.** Число загруженных блюд на семью (читается из журнала: действие «Загрузка блюд из Excel»).

## Review Focus

1. Двойной тап по «Загрузить» — блюда не дублируются (после первого вызова повторный `importDishes` с теми же блюдами отвечает «уже есть»).
