# Загрузка блюд из Excel: формат файла

Вкладка «Блюда» → «📄 Бланк блюд» скачивает готовый файл с тремя примерами. Заполните его и загрузите кнопкой «📥 Загрузить блюда из Excel». Принимается только этот формат: один лист, первая строка (заголовок) не меняется.

## Столбцы

| № | Столбец | Что писать | Если пусто |
|---|---|---|---|
| 1 | Блюдо | название; пишется в первой строке блюда | строка продолжает предыдущее блюдо |
| 2 | Тип | основное, гарнир или салат (также «доп») | основное |
| 3 | Приёмы пищи | через запятую: завтрак, обед, ужин | все три |
| 4 | С гарниром | да или нет | нет |
| 5 | Порций в рецепте | число | приложение считает 4 |
| 6 | Хватает на, раз | целое число от 1 | 1 |
| 7 | Заметка | любой текст | без заметки |
| 8 | Продукт | название продукта | блюдо без состава |
| 9 | Количество | число (можно с запятой: 0,5) | обязательно, если указан продукт |
| 10 | Ед. | кг, г, л, мл или шт | для нового продукта обязательна |

Столбцы 2–7 берутся из первой строки блюда, в следующих строках их повторять не нужно. Каждая следующая строка блюда добавляет один продукт.

## Пример

| Блюдо | Тип | Приёмы пищи | С гарниром | Порций | Хватает на | Заметка | Продукт | Количество | Ед. |
|---|---|---|---|---|---|---|---|---|---|
| Плов с курицей | основное | обед, ужин | да | 6 | 2 | | Рис | 0,5 | кг |
| | | | | | | | Курица | 800 | г |
| Гречка отварная | гарнир | обед, ужин | | 4 | 1 | | Гречка | 250 | г |

## Что произойдёт

- Перед загрузкой приложение покажет список: 🆕 новое блюдо, ✔️ уже есть, ⚠️ ошибка (с причиной). Ничего не добавится, пока вы не нажмёте «Загрузить».
- **Блюдо с таким названием уже есть** (регистр, пробелы и «ё/е» не важны) — оно пропускается, существующие блюда и их состав не меняются.
- **Продукт уже есть на складе** — берётся он, остаток не трогается. Единица в файле должна быть из той же семьи: кг и г, л и мл; «шт» только к «шт».
- **Продукта нет на складе** — он создаётся: единица из файла (обязательна), остаток 0, минимум 0.
- Один продукт дважды в блюде — количества складываются.
- Ошибка в любой строке блюда — это блюдо не загружается, остальные загружаются.
- Файл не по этому формату — загрузка не начнётся; скачайте бланк и заполните его.
- За один раз — не больше 500 блюд и 5000 строк.
